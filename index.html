🛠️ Technical Details

Cache System Architecture:

  1. Download large area (10km radius) → Cache to disk (~38MB)
  2. Load cached graph from disk (~1.25s)
  3. Find nearest node to target coordinates
  4. Extract subgraph using distance-based truncation
  5. Return smaller network for analysis

  • osmnx_cache/toronto_large.pkl - Cached graph data (38MB)
